# Stayshay mobile (iOS + Android)

Expo SDK 58 + expo-router. Listings come from the website's `/api/listings`; shared logic from `@stayshay/core`.

```bash
npx expo start          # scan with Expo Go (same Wi-Fi as the Mac running the website)
npm run icons           # regenerate icons/splash/store graphics from the brand mark
```

Screens: Explore · Search · Roommates · List your place · Saved · Listing detail (viewing request → WhatsApp).

Publishing to the App Store and Google Play: see [docs/LAUNCH.md](../../docs/LAUNCH.md).
